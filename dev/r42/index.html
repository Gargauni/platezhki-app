Вход в трекер

Данные хранятся в закрытом репозитории на GitHub. Введите ключ доступа один раз на этом устройстве — дальше трекер будет открываться сразу, а изменения сохраняться сами.

Ключ хранится только в этом браузере. Потеряли устройство — отзовите ключ на github.com, и доступ пропадёт.
Открыть файл с диска (по-старому, через GitHub Desktop)

Этот браузер не умеет сохранять в файл напрямую. Откройте страницу в Chrome или Edge. Здесь изменения придётся скачивать вручную и заменять ими data/tracker.json.

Здесь появятся документы к оплате

1. Сканы в папку inboxНа личном ПК Claude Code командой /inbox разносит сканы УПД и счетов в tracker.json.
2. Синхронизация через GitHubНа рабочем ПК нажмите Fetch/Pull в GitHub Desktop, чтобы получить свежие данные.
3. Выгрузка в банкВ платёжный день — «Выгрузить в банк», файл загружается в СДМ, остаётся подписать.

Как отсканировать на iPhone
  1. Откройте «Файлы» → вкладка «Обзор» → «…» вверху → «Сканировать документы». Или «Заметки» → скрепка → «Сканировать документы».
  2. Наведите на лист: сканер сам найдёт края и снимет. Снимите все страницы документа подряд → «Сохранить».
  3. Вернитесь сюда → «Выбрать файлы» → выберите сохранённый PDF.
