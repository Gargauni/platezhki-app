# platezhki-app

Код трекера платежей поставщикам (GitHub Pages). Данных здесь нет: трекер читает и сохраняет их
в закрытом репозитории по ключу доступа, который вводится на каждом устройстве.

- `/` — рабочая версия (R8), настоящие данные
- `/dev/` — черновик, тестовая копия данных (ветка sandbox)
